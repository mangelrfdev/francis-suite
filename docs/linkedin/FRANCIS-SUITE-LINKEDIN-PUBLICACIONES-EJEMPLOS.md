## 1) Ejemplo Senior (tecnico + producto)

Hoy comparto un proyecto que resume muy bien mi enfoque de ingenieria de datos: **Francis Suite**.

Objetivo: pasar de scripts de scraping sueltos a un framework declarativo, mantenible y reutilizable.

### Stack
- Python
- XML workflows
- lxml + XPath
- httpx
- Playwright

### Decisiones clave
- separar parser, runtime y contexto para reducir acoplamiento,
- usar hands reutilizables para escalar casos de uso sin duplicar logica,
- modelar estado con boxes para trazabilidad de datos,
- exportar en formatos operativos (incluyendo NDJSON) para integracion real.

Aprendizaje: la diferencia entre "extraer datos" y "construir plataforma" esta en disenar para evolucion, control y observabilidad desde el inicio.

Si te interesa, feliz de compartir arquitectura y roadmap tecnico.
