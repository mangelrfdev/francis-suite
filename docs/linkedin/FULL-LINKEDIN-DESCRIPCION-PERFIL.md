## 2) Seccion "Acerca de" (Version Senior)

Soy desarrollador con foco en construir productos digitales completos: desde la ingenieria de datos hasta la experiencia de usuario, incluyendo infraestructura y deploy.

Mi portfolio tecnico tiene dos proyectos que se complementan:

Un **framework propio en Python** donde los pipelines de datos se definen en XML y se ejecutan con un runtime por capas (parser, contexto, motor y handlers reutilizables). Trabajo con lxml, httpx y Playwright, containerizado con Docker y deployado en Oracle Cloud (infraestructura principal) con experiencia adicional en GCP.

**EstacionInmobiliaria.cl** — plataforma web de busqueda inmobiliaria construida sobre los datos que produce ese framework. Implementada con Next.js 14, TypeScript y Supabase/PostgreSQL, con deploy continuo en Vercel y foco en estados de interfaz bien resueltos, filtros avanzados y experiencia calmada en mobile y desktop.

Lo que mas valoro de trabajar en ambos extremos: los problemas de UX muchas veces tienen raiz en como se estructuran los datos, y controlar tambien el deploy de cada capa permite iterar con mucha mas velocidad y criterio.

Stack habitual: Python, lxml, httpx, Playwright, Docker, Oracle Cloud, GCP · Next.js, TypeScript, Tailwind, Supabase, PostgreSQL, Vercel.

## 6) Tips para este perfil

- Si apuntas a roles de **data engineering o backend/cloud**: pon el framework primero, menciona Docker y Oracle Cloud/GCP como experiencia de infraestructura real.
- Si apuntas a roles de **full stack o producto**: enfatiza el rango end-to-end, desde el pipeline hasta el deploy en Vercel.
- Si apuntas a roles de **frontend**: pon Estacion Inmobiliaria primero, menciona el framework como prueba de que entiendes el origen y estructura de los datos.
- En todos los casos: muestra decisiones tecnicas concretas, no solo lista de herramientas.
